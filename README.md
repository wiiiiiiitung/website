# DWEI Website

Landing page for DWEI's Dragon Dust seasoning line. Plain HTML/CSS/JS, no build step — just open `index.html` or serve via GitHub Pages.

## To update before going live

- `index.html` — Contact tab has placeholder phone number, email, and social links marked "update me" / "add link". Replace with real values.
- Product descriptions in the Products tab are drafts — edit copy as needed.
- Colors/branding live in `styles.css` under `:root` if you want to adjust the palette.

## Local preview

Just open `index.html` in a browser, or run a quick local server:

```
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
